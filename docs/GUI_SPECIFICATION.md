# GUI revision
1043 × 366 vector panel with fixed aspect ratio; 32 px preset toolbar above the 1043 x 366 panel. Preset operations are also available from the panel context menu. Display legends follow the supplied historical reference at the user’s request; plugin identity and parameter IDs remain PLATE 140.

Fine seeded cream paint grain (#E2DCC8), subtle stains and vignette, granular cork surround (#A8744A), bold condensed black (#1A1A1A) typography. Cached material image prevents re-rendering thousands of grain particles on meter updates. No horizontal brushed-metal lines.

Unboxed clickable A/B/C letters, black bevelled reverb meter housings, metallic screws, deep recessed windows, radial yellow scales (#E8DFB5), fine red pointers and diagonal glass reflections. Scale legends: max / 5 / sek. / 4 / 3 / 2 / 1 / min.

Serrated knobs with radial concave faces, curved upper-left specular highlight, white index and 6 px / 35% cast shadow; chrome toggles; rectangular bevelled metal filter cursor and red ticks. Pale-framed VU with desaturated cream face, curved reflection and fine black needle. Metallic LED bezel and 18 px red shadow/glow. Lighting follows upper-left highlights and lower-right shadows.

All audio parameter attachments are retained. Presets, A/B, reset and XML import/export are available on right-click. Screenshot: images/plate140.png.

Preset toolbar opens a separate 390 x 700 desktop window (resizable 350 x 500 to 650 x 1000), with native drag title bar and close button. No modal loop: panel controls remain usable. Browser uses lightweight vector controls and visible-row list painting; it does not create 100 graphic assets. Search, category, single tag and favourite filters combine. User category is always available. Data is saved outside the audio callback, with a per-library interprocess lock, reload-before-mutate and atomic replacement. MAP is an automation-ID reference, not MIDI Learn.
