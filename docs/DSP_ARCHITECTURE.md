# Architecture
Independent double-precision 16-line orthogonal Householder feedback-delay network with four serial input allpass diffusers, frequency-dependent feedback damping, distinct incommensurate plate delay lengths and signed stereo pickup matrices. This is a plate-inspired approximation, not a physical finite-element plate solver or a copy of a proprietary algorithm.

Input -> per-instance input shelf -> restrained tanh driver -> diffusion -> three continuously running plate tanks -> 50 ms smoothed plate selection -> fractional wet predelay -> per-instance two-band shelf EQ -> mid/side width -> independent balance attenuation -> linear amplitude dry/wet blend -> RMS ballistic VU. Knob position to predelay/mix uses a nonlinear exponent; center maps exactly to 50 ms / 15%. Dry path has no intentional delay. Wet Solo overrides mix without overwriting it. Power bypass is smoothed, and suspends tanks after fade-out.

Feedback amplitude is 10^(-3 delaySeconds / RT); low-pass damping shortens high-frequency decay. Plate B includes a measured short-time correction (see VALIDATION.md). Modulation varies RT by 2^(cents*sin(phase)/1200), with zero depth exactly stationary. This approximates decay modulation rather than a calibrated pitch excursion. All delay storage is allocated in prepare; callback uses fixed storage, no locks or I/O. Each tank retains its own RT. All tanks run during power-on to permit smooth switching.
